# Lê pra Mim

Leitor Android de páginas fotografadas, com OCR local e narração em português. Projeto inicial sem APIs pagas.

Abra no Android Studio com JDK 17 e SDK 35. A compilação de debug usa Gradle 8.9 e AGP 8.7.3.

As vozes disponíveis dependem do mecanismo TTS instalado. Vozes de rede podem enviar texto ao provedor. A captura é manual; não há leitura contínua da câmera.
